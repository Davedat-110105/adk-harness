# Examples

`agents/workspace/agent.py` shows a governed local ADK Workspace application
with an explicit service and operation allowlist. `scripts/workspace_policy_demo.py`
is an opt in live example for a configured Google account; it can create a
calendar event after an approval precedent and explains the manual cleanup.

Examples do not perform cloud onboarding or automatic history transfer. Review
the requested scopes and policy before running a live example.
