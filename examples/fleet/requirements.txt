# Installed into the Cloud Run container.
#
# adk-harness is not on PyPI yet, so it comes from the public repo. Note this is
# an HTTPS tarball, not `git+https://` — ADK generates a `python:3.11-slim`
# Dockerfile, and slim images have no git binary, so a git URL fails the build.
# codeload serves the same tree over plain HTTPS, which pip can fetch unaided.
#
# coactra and google-adk arrive as transitive dependencies.
